# Serotonin 범용 OBD

현재 공개 버전은 **2.0**(`versionCode 3`)입니다.

안드로이드 차량 진단 앱. **Vgate iCar Pro ELM327 BT3.0** 등 Bluetooth Classic 어댑터로
표준 OBD-II 오류코드를 읽고, 표준 OBD가 통하지 않는 차량(전기차 등)은 ECU 를 직접 찾아 읽습니다.

> 원래 2019년식 Nissan Leaf 진단용으로 시작했으나(구 이름 LeafOBD),
> 표준 OBD-II 차량과 UDS 응답 차량을 두루 다루게 되어 범용으로 확장되었습니다.
> 패키지 ID(`com.eunho.leafobd`)는 호환을 위해 유지합니다.
> 제작자: 이은호 (serotonin.1207@gmail.com)

> ⚠️ 이 앱은 개인 진단 보조 도구이며 정비소의 전문 진단을 대체하지 않습니다.
> 오류코드 삭제는 고장을 수리하지 않습니다.
> 고전압 배터리, 절연, 충전기, 브레이크, 에어백 관련 이상이 있으면 차량을 운행하거나 충전하지 말고 전문 점검을 받으십시오.
>
> 작업 전 반드시 [SAFETY.md](SAFETY.md) 를 읽으십시오.

## 1. 앱 목적

다음 증상의 원인을 찾기 위한 1차 자료(오류코드 + 원시 응답)를 확보합니다.

- 계기판에 `EV SYSTEM` 경고 표시
- 충전기를 연결해도 충전이 시작되지 않음
- 충전 접촉기 작동음이 들리지 않음
- 12V 배터리 음극 분리 리셋으로 해결되지 않음

### 프리즈 프레임이 왜 중요한가

프리즈 프레임은 **고장이 확정되던 순간의 데이터 스냅샷**입니다.
Mode 04(표준 삭제)를 실행하면 차량에서 **함께 지워집니다.**

그래서 이 앱은 DTC를 읽기 **전에** 프리즈 프레임을 먼저 읽어 로그에 저장합니다.
삭제 후에는 이 로그 파일이 유일한 사본이 됩니다.

### 다른 차량에도 쓸 수 있습니다

앱은 표준 OBD-II 명령과 제한된 읽기 전용 UDS 요청을 사용합니다.
홈의 `내 차 지원 범위`에서 선택 차량의 기능별 상태를 확인할 수 있습니다. 상태는 `지원`, `부분 지원`, `실차 검증 필요`, `미지원`으로 나뉘며 연식·판매 지역·ECU 차이 때문에 표준 OBD도 부분 지원으로 안내합니다.

실제로는 **일반 내연기관 차량에서 더 많은 정보가 나옵니다.**
표준 OBD-II 가 배출가스 진단 규격이라, 가솔린 차에서는 RPM·냉각수 온도·
연료 트림·프리즈 프레임이 표준으로 제공되지만 전기차에는 해당 항목이 아예 없습니다.

단, ABS · 에어백 · TPMS · 변속기 같은 제조사 전용 계통은
**어느 차량에서도** 표준 OBD-II 로 읽을 수 없습니다.

## 3. 지원하지 않는 범위

- Nissan Leaf ZE1 제조사 진단은 일부 읽기·조건부 삭제 후보만 제공하며 모든 ECU와 코드 정의를 지원하지 않습니다. ([배경](app/src/main/java/com/eunho/leafobd/nissan/README.md))
- Leaf ZE1·Niro EV DE의 배터리 SOC·SOH·셀 전압·온도 직접 읽기는 구현 후보이며 기준 진단기 대조 전까지 `실차 검증 필요`입니다.
- ECU 코딩, 펌웨어 변경, 보안 접근 우회
- 고전압 시스템·접촉기·충전 강제 제어
- 에어백 · ABS · 브레이크 관련 명령
- 계정, 광고, 분석 SDK 또는 진단 데이터 전송. 인터넷은 앱 버전 확인과 사용자가 요청한 서명된 공개 오류코드 데이터 갱신에만 사용합니다.

표준 OBD-II는 배출가스 관련 진단을 위한 규격입니다.
**Leaf의 EV 계통 오류가 표준 명령으로 읽히지 않을 수 있으며, 이는 앱의 결함이 아닙니다.**

### 남에게 줄 때는 반드시 release 빌드로

debug APK 는 `android:debuggable=true` 라서 USB 디버깅이 켜진 폰에서는
`adb run-as` 로 앱 내부의 진단 로그를 꺼낼 수 있습니다. 배포에 쓰지 마십시오.

**1단계 — 서명 키 만들기 (최초 1회)**

프로젝트 폴더에서 실행합니다. 비밀번호는 직접 정하십시오.

```bash
"C:\Program Files\Android\Android Studio\jbr\bin\keytool.exe" -genkeypair -v -keystore leafobd-release.jks -alias leafobd -keyalg RSA -keysize 2048 -validity 10000
```

**2단계 — `keystore.properties` 작성**

`keystore.properties.example` 를 복사해 `keystore.properties` 로 저장하고 값을 채웁니다.
이 파일과 `.jks` 는 `.gitignore` 에 등록되어 있어 저장소에 올라가지 않습니다.

**3단계 — 빌드**

```bash
.\gradlew.bat assembleRelease
```

> ⚠️ **키스토어 파일과 비밀번호를 잃어버리면 같은 앱으로 업데이트할 수 없습니다.**
> 지인들이 기존 앱을 지우고 새로 설치해야 합니다. 반드시 따로 백업하십시오.

배포·설치 안내는 [INSTALL.md](INSTALL.md) 를 그대로 전달하시면 됩니다.


## 9. Bluetooth 페어링 방법

앱은 **이미 페어링된 장치만** 표시합니다. 페어링은 시스템 설정에서 먼저 해야 합니다.

1. 차량을 안전한 상태(P, 주차 브레이크, 충전 케이블 분리)에 둡니다.
2. 어댑터를 운전석 하단 OBD2 포트에 꽂습니다. (어댑터 LED 점등 확인)
3. 폰에서 **설정 → 연결 → Bluetooth**
4. `V-LINK`, `OBDII`, `Vgate`, `iCar Pro` 등으로 표시되는 장치를 선택합니다.
5. PIN을 요구하면 **판매자 설명을 먼저 확인**하십시오. (앱은 PIN을 단정하지 않습니다)
6. 페어링이 끝나면 Serotonin OBD 앱 → **어댑터 연결** 화면에서 목록을 새로 고칩니다.

앱 안에서 무리하게 페어링을 구현하지 않고 시스템 Bluetooth 설정으로 보냅니다.

## 10. 진단 절차

```text
어댑터 연결
 → ELM327 초기화
 → 어댑터 정보(ATI) · 전압(ATRV) 확인
 → 차량 정보 (0101 경고등 · 지원 PID · VIN)
 → 프리즈 프레임 저장 (Mode 02)   ← 삭제하면 사라지므로 먼저 읽는다
 → Mode 03 / 07 / 0A 읽기
 → 원시 응답 저장 (TXT + JSON)
 → 코드 검토
 → (필요 시) 사용자 이중 확인
 → 표준 오류 삭제 1회
 → 3초 후 자동 재조회
 → 재발 코드 확인
 → 필요 시 전문 점검
```

자세한 순서는 앱 안의 **사용 절차** 화면과 [TESTING.md](TESTING.md) 를 참고하십시오.

### 어댑터가 없을 때 — 테스트 모드

**설정 → 테스트 모드** 를 켜면 실제 어댑터 없이 전체 흐름을 확인할 수 있습니다.
시나리오 5가지(표준 응답 / 삭제 후 재발 / 데이터 없음 / 통신 오류 / 무응답)를 제공하며,
이 모드에서는 모든 화면에 **"모의 데이터"** 배지가 표시됩니다.

## 11. 로그 파일

저장 위치는 앱 내부 저장소이며, 진단 기록 화면에서 공유·복사·삭제할 수 있습니다.

```text
LeafOBD_2026-07-29_223500.txt    사람이 읽는 형식
LeafOBD_2026-07-29_223500.json   구조화된 형식
```

- Bluetooth MAC 주소는 마지막 2바이트만 남기고 마스킹합니다. (`**:**:**:**:98:8B`)
- 차대번호(VIN)는 기본적으로 읽지 않으며, 켜더라도 파일에는 마스킹해 저장합니다. (`SJN**********2345`)
- 위치정보를 수집하지 않습니다.
- 인터넷으로 전송하지 않습니다. 공유는 사용자가 직접 눌렀을 때만 동작합니다.

## 12. 안전 주의사항

- 진단 중 충전 케이블을 분리하십시오.
- 고전압 케이블(주황색)과 배터리 팩을 절대 만지지 마십시오.
- 삭제 기능은 로그 저장 후에만 활성화되며, 한 세션에 **1회만** 실행됩니다.
- 코드가 삭제 직후 다시 나타나면 **활성 고장**일 수 있습니다. 반복 삭제하지 말고 점검을 받으십시오.
- 타는 냄새, 연기, 비정상 발열, 절연 오류, 브레이크·에어백 경고 시 **즉시 중단**하십시오.

차량 지원 판정 카탈로그는 사용자 확인 차량과 범용 규칙을 분리합니다. 현재 전용 항목은 2019 닛산 리프 ZE1과 2019 기아 니로 EV DE입니다. 북미 공식 공개 문서와 판매 지역·연식·세대·동력계·엔진이 정확히 일치하는 쏘나타 하이브리드 YF, Soul PS, Rio/Rio5 JB, IONIQ Hybrid 사례도 별도 항목으로 식별합니다. 대한민국에서 운행되는 현대·기아·제네시스·닛산·토요타·쉐보레·르노코리아·KGM 주요 차종 83개 계열은 실차 검증 자료를 모으는 개별 대상군으로 분류합니다. 차량 추가 화면에서 계열을 선택한 뒤 연식·세대·동력계·사양을 직접 확인해야 합니다. 카탈로그 일치는 지원 완료나 고장 없음 판정이 아닙니다.

지원 범위 화면에는 `국제 표준 → 제조사 그룹 → 플랫폼·시스템 → 차종 계열 → 연식·사양 일치` 데이터 계층을 표시합니다. 공통 OBD로 확인된 코드는 제조사 사이에서 재사용할 수 있지만, 같은 제조사나 플랫폼이라는 이유만으로 제조사 전용 코드·ECU 주소·수리 절차를 복사하지 않습니다. E-GMP와 리프 ZE0/AZE0/ZE1처럼 공개 근거가 있는 관계도 검색 후보를 좁히는 용도로 사용하며, 실제 해설 연결에는 차종·연식·시장·동력계 조건의 별도 근거가 필요합니다.

현대·기아 파워트레인 공개 근거표는 7개 시스템과 12개 적용 조건으로 시작합니다. 현대 7단 건식 DCT, 기아 Gamma 1.6 T-GDI·7DCT, 니로 DE 하이브리드 1.6 Atkinson·6DCT, Santa Fe TM Gamma II 1.6T 하이브리드, Sonata YF HEV Theta II 2.4와 고전압 전력 릴레이 계통, 현대 2.5T·8단 습식 DCT를 포함합니다. 차량명·연식·동력계가 맞아도 엔진·변속기 입력이 없으면 추가 확인으로 표시하고, 북미 공개 문서는 대한민국 차량에 자동 적용하지 않습니다. 차량 등록 중 후보를 확인하고 저장 후 지원 범위 화면에서 원문 적용표를 열 수 있습니다.

차량별 DTC 근거표에는 제조사 공지에 실제로 기재된 11개 코드가 연결돼 있습니다. Santa Fe TM HEV/PHEV 공지의 P1441·P1A77·P00B7·P2118·P0401·P0236·P0299와 Sonata YF HEV 공지의 P0A0D·P1B25·P1B76·P1B77입니다. 11개 모두 동일 적용 차량의 후속 공식 문서에서 다시 확인했습니다. 7개는 별도 공식 문서에서 의미를 대조했고, P0A0D는 SAE 표준 체계와 현대·기아 문서를 함께 대조했습니다. 공통 코드 해설 근거 충족 6개와 제조사·차량 범위 유지 5개로 구분합니다. 이는 다른 문서의 수리법을 현재 차량에 적용한다는 뜻이 아닙니다. 일반 해설이 없는 경우에는 원인이나 부품을 추측하지 않습니다.

대한민국 공식 사양 카탈로그는 현대·기아 30개 조합을 포함합니다. 싼타페·니로·아반떼·코나·그랜저·투싼·쏘나타·K8·스포티지·쏘렌토·카니발·모닝의 내연기관/하이브리드와 EV3·EV6·아이오닉 5 N의 전기차 사양을 제조사 국내 페이지·카탈로그에서 확인했습니다. 같은 차종에 엔진이나 배터리가 여러 개면 배기량 또는 배터리 용량과 구동방식을 추가 입력하기 전까지 `세부 사양 확인 필요`로 표시합니다. 배터리 용량·모터 출력은 차량 사양 식별 자료이며 앱의 SOC·SOH 측정 지원을 뜻하지 않습니다. 국내 사양과 북미 문서의 플랫폼·동력계가 일부 겹치더라도 국내 DTC 적용이 확인됐다고 표시하지 않습니다.

오류코드 해설 데이터는 현재 105건(공통 OBD 102건, 제조사 전용 3건)이며 34개 공식 근거 문서·표준 메타데이터와 연결됩니다. 흡기·온도·스로틀·산소센서·연료 보정·연료 압력·분사기·점화·EGR·증발가스·전압·변속기·차량 통신·하이브리드/EV 배터리 계통을 다룹니다. P00B7·P2118·P0236·P0299와 P0A0D에는 차량 공통 의미, 조건부 운행 안내, 사용자 점검, 정비사 전달 정보와 삭제 전 보존 항목을 추가했습니다. P0A0D의 High는 배터리 과전압이 아니라 인터록 감시 회로 상태이며, 사용자가 고전압 커넥터나 서비스 플러그를 만지지 않도록 안내합니다. 특정 공지의 원인·임계값·부품 교체 절차는 다른 차종에 적용하지 않습니다. 자동으로 웹 데이터를 수집하는 구조가 아니며, 제조사·공식 공개 자료의 적용 범위와 라이선스를 사람이 확인한 자체 요약만 앱에 포함합니다. 확인되지 않은 접미 코드나 국내 적용 여부는 미검증 상태로 표시합니다.

홈의 **미해설 코드 대기함**은 차량별로 분류한 저장 기록에서 아직 해설이 없는 코드를 모아 발생 세션 수와 ECU를 정리합니다. 내보내기 내용은 차량 별칭을 익명화하고 VIN, 블루투스 주소, 원시 응답과 정확한 시각을 포함하지 않습니다. 이 목록은 새 해설 후보를 찾기 위한 자료이며 코드의 의미나 원인을 자동 확정하지 않습니다.

새 진단 JSON(`reportSchema 2`)에는 진단 당시 차량 프로필과 차량 카탈로그 ID·리비전의 스냅샷을 저장합니다. 프로필을 나중에 수정하거나 삭제해도 해당 기록의 모델 계열은 바뀌지 않습니다. 프로토콜 식별, 표준 OBD 데이터 관찰, 제조사 ECU 응답 수도 별도의 관찰 사실로 저장합니다. 미해설 코드 대기함은 모델 계열별 차량 수·기록 수·후보 수·코드 수신 세션 합계와 통신 관찰 건수를 표시합니다. 이전 형식 기록은 현재 프로필을 대입해 추정하거나 통신 실패로 계산하지 않고 `차량 계열 미저장`으로 유지합니다.

오류코드 해설은 `운행 중단·견인 검토`, `빠른 전문 점검`, `조속한 점검 예약`, `증상·동반 코드 우선 확인`의 네 대응 단계로 표시합니다. 이는 코드만으로 내린 운행 허가가 아니며 실제 경고등, 냄새·발열, 출력 제한, 충전·제동 이상이 있으면 화면의 조건부 안내를 우선합니다. 각 해설에는 직접 확인할 항목, 정비사 전달 항목, 삭제 전에 저장할 기록이 구분되어 있습니다.
